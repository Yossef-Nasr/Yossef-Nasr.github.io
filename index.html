E-Commerce & Clothing
Donation App
E-Commerce & Clothing Donation App is a Flutter-based E-Commerce application I built, combining core shopping features (product browsing, search, and cart management) with a clothing donation system designed around a realistic multi-step workflow.

The donation feature allows users to select the clothing items and quantities they want to donate, choose a donation organization, specify their preferred contact method and pickup time, review the donation details, submit the request, and track its status. The complete flow is managed using Cubit, while donation data is persisted locally using Hive with generated TypeAdapters.

The application also includes REST API integration using Dio, secure authentication with Access/Refresh Token handling through Dio interceptors, and flutter_secure_storage for sensitive authentication data. Network connectivity monitoring and responsive UI were also implemented to provide a more reliable user experience.

The project follows a Feature-Based Architecture with Clean Architecture-inspired principles, focusing on separation of responsibilities and maintainable feature modules.

Tech Stack: Flutter · Dart · BLoC/Cubit · Dio · Hive · GoRouter · GetIt (DI) · Equatable · dartz (API error handling) · flutter_secure_storage
